# RULES.md · 写作纪律基准

> **这是本体系的最高约束**。故事设定的验收引用它，`guard_novel.py` 从它读数值做校验。
> 规则定义权在你手里 —— 脚本只负责执行与兜底。
>
> 改规则 = 改下面 `RULES-BEGIN / RULES-END` 之间的键值对。**格式别动**。

---

## 零、机器可读规则块（★ 脚本读这里）

<!-- RULES-BEGIN -->
min_words_per_chapter = 1500
max_words_per_chapter = 8000
require_outline_for = novella, novel
require_thread_close = true
freeze_accepted_world = true
check_banned_terms = true
<!-- RULES-END -->

| 键 | 含义 | 默认值 | 说明 |
|---|---|---|---|
| `min_words_per_chapter` | 单章最少字数 | 1500 | 低于这个数说明这章没写完，或者该合并 |
| `max_words_per_chapter` | 单章最多字数 | 8000 | 超过说明该拆章（读者会累） |
| `require_outline_for` | 哪些篇幅必须有章纲 | novella, novel | flash / short 不需要 |
| `require_thread_close` | 完结前伏笔必须闭环 | true | 挖坑不填是长文最大的坑 |
| `freeze_accepted_world` | 世界观 accepted 后冻结 | true | 改它必须走变更单 |
| `check_banned_terms` | 扫描术语的禁止写法 | true | 同一概念多种叫法的克星 |

## 一、世界观纪律（硬约束）

- **世界观 accepted 后冻结**。要改，必须同时做两件事：① 在 `world.md` 第七节留一行变更记录
  ② 在 `changes/` 建变更单，写清影响哪些已写故事。**偷偷改设定，脚本会拦。**
- **没写进世界观的设定不算数**。想临时用，记在故事的「本篇新增的设定」里，
  写完决定提升还是作废。
- **同一个概念只能有一种写法**。术语表的「禁止写法」列出来就是为了让脚本扫。

## 二、一致性纪律

- **人物出场前先有卡**。没有人物卡的人，不许当重要角色写。
- **人物状态以人物卡为准**。`status: dead` 的人在他死后时间线的章节里不许出场（除回忆，且要标注）。
- **地点先有卡再写**。写到没登记的地方，要么建卡，要么明确它不重要。
- **时间线单调递增**。倒叙必须显式标注 `flashback`。

## 三、故事纪律

- **先写「不写什么」再动笔**。短篇写崩基本都是塞太多。
- **伏笔必须闭环**：埋下的每条，最后要么 `paid`，要么 `dropped` 并写清原因。
- **完结前跑一次全量校验**，别指望"我记性好"。

## 四、写作纪律

- **每章必须完成一件事**，且这一章结束时局面有不可逆变化。
- **章末必须有钩子**，否则读者凭什么点下一章。
- **视角不跳**。一章之内不换视角人物，除非那是刻意的结构。
- **不用形容词堆情绪**（"他感到无比的悲伤"），用动作和细节。
