# RULES.md · 投资纪律基准

> **这是本体系的最高约束**。决策书 validation 章节引用它，`guard_invest.py` 从它读数值做校验。
> 规则定义权完全在你手里 —— AI 只负责执行与兜底，不替你改规则。
>
> 改规则 = 改下面 `RULES-BEGIN / RULES-END` 之间的键值对。**格式别动**，脚本靠它解析。

---

## 零、机器可读规则块（★ 脚本读这里）

<!-- RULES-BEGIN -->
max_single_weight = 20
max_equity_weight = 80
stop_loss_pct = -8
forbid = 杠杆, 融资, 追涨停, T+0, ST, 退市风险股
require_strategy_accepted = true
<!-- RULES-END -->

| 键 | 含义 | 默认值 | 你怎么改 |
|---|---|---|---|
| `max_single_weight` | 单标的仓位上限 % | 20 | 按自己风险偏好调 |
| `max_equity_weight` | 权益类总仓位上限 % | 80 | 留出现金缓冲就别改成 100 |
| `stop_loss_pct` | 个股止损线 %（负数） | -8 | 越保守越接近 0 |
| `forbid` | 禁止项清单（逗号分隔） | 杠杆,融资,… | 加你自己的雷区 |
| `require_strategy_accepted` | 决策书引用策略包时是否必须 accepted | true | 前期觉得麻烦可设 false |

---

## 一、通用纪律（硬约束）

- **单标的仓位上限**：≤ 20%
- **总仓位规则**：权益类 ≤ 80%，其余留现金 / 货基
- **止损纪律**：个股 -8% 强制评估；**达到止损线必须执行，或写书面例外理由**
- **禁止项**：不杠杆、不融资、不追涨停、不做 T+0、不碰 ST / 退市风险股

## 二、决策规定

- **任何买入前必须有 accepted 决策书**；无决策书不交易（这是本体系的地基）
- **投资假设必须可证伪**：写清楚「什么情况证明我看错了」，且带可验证指标
- **卖出理由必须写**：逻辑破坏 / 达到目标 / 风险事件，三选一
- **计划外加减仓**必须新开决策书走 review，不许在旧决策书上打补丁

## 三、持仓规定

- **每周检查一次**持仓卡的逻辑是否仍成立（生成 task.monitor.md）
- 仓位漂移超过上限 → 必须在下一交易日前处理

## 四、复盘规定

- **每笔 closed 必须复盘**，重点三项：假设兑现对照 + 纪律遵守情况 + 情绪反思
- **复盘发现的规则漏洞 → 追加到本文件**（这是经验沉淀的唯一入口，别写在别处）
